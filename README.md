# MERN Stack Internship - Week 1

## About

This repository contains my Week 1 assignments and mini project for my Full Stack Web Development (MERN) Internship.

The week focuses on frontend fundamentals including HTML5, CSS3, JavaScript and React.

---

## Projects

### 1. Personal Portfolio Website

A responsive personal portfolio website built using HTML5 and CSS3.

#### Features

- Semantic HTML5 structure
- About section
- Education section
- Projects section
- Contact section
- CSS Flexbox
- CSS Grid
- Responsive design

---

### 2. React Components Practice

A React application demonstrating reusable components and fundamental React concepts.

#### Components

- Header
- Footer
- Card
- Button
- Form

#### React Concepts

- Components
- Props
- State
- Events
- Dynamic rendering
- `useState`

---

### 3. React Blog UI

A responsive React-based blog interface.

#### Features

- Blog posts stored in JSON
- Reusable BlogCard component
- Dynamic post rendering
- Search functionality
- Category filtering
- Responsive design
